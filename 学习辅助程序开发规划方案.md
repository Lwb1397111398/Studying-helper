## 1. 系统概述

### 1.1 项目目标

构建一个智能化的学习辅助系统，通过AI自主学习书籍内容，然后以个性化的教学方式帮助用户高效掌握知识。

### 1.2 核心价值主张

- **AI先行学习**：AI先深度理解书籍，再教用户，确保教学质量
- **个性化适配**：根据用户学习风格动态调整教学策略
- **闭环学习**：学习→评估→反馈→再学习的完整循环
- **成本优化**：智能缓存和增量学习机制，降低token消耗

### 1.3 系统边界

```
┌─────────────────────────────────────────────────────────────┐
│                    学习辅助系统边界                           │
├─────────────────────────────────────────────────────────────┤
│  输入层：书籍文件（PDF/TXT/EPUB等）                          │
│  处理层：AI自主学习 → 方案制定 → 教学 → 复习评估             │
│  输出层：知识图谱、学习方案、教学内容、学习报告               │
│  存储层：学习成果、用户画像、历史记录                         │
└─────────────────────────────────────────────────────────────┘
```

#### 3.1.4 选择性学习

用户不需要按顺序学完整本书。支持选择特定章节、跳过已知内容，按需学习。

```python
class SelectiveLearning:
    def get_book_overview(self, book_id: str) -> BookOverview:
        """生成书籍概览，供用户选择学习范围"""
        book = self.db.get_book(book_id)
        chapters = self.db.get_chapters(book_id)
        return BookOverview(
            title=book.title,
            total_chapters=len(chapters),
            chapters=[
                ChapterBrief(
                    id=ch.id,
                    title=ch.title,
                    key_concepts=ch.summary[:3],  # 前3个核心概念
                    estimated_time=ch.estimated_minutes,
                    difficulty=ch.difficulty_level
                )
                for ch in chapters
            ]
        )

    def create_partial_plan(self, user_id: str, book_id: str, 
                            selected_chapter_ids: List[str]) -> LearningPlan:
        """为用户选择的章节生成学习方案"""
        # 分析选中章节之间的依赖关系
        dependencies = self.analyze_dependencies(selected_chapter_ids)
        # 如果有缺失的前置章节，提示用户
        missing_prereqs = self.find_missing_prerequisites(
            selected_chapter_ids, dependencies
        )
        if missing_prereqs:
            self.suggest_prerequisites(user_id, missing_prereqs)
        # 按拓扑排序生成学习顺序
        ordered = self.topological_sort(selected_chapter_ids, dependencies)
        return self.plan_generator.create_plan(user_id, book_id, ordered)
```

#### 3.1.5 Token优化策略

**问题**：完整书籍可能需要大量token，成本高昂

**解决方案**：

1. **分层摘要压缩**
   ```
   原始内容（10000 tokens）
      │
      ▼
   章节摘要（1000 tokens）→ 存储到数据库
      │
      ▼
   核心要点（200 tokens）→ 用于快速检索
      │
      ▼
   知识图谱节点（50 tokens）→ 用于关联查询
   ```

2. **增量学习机制**
   - 首次学习：完整处理，生成各层级摘要
   - 二次学习：基于已有摘要，只补充增量内容
   - 关联学习：只处理新增的关联关系

3. **智能缓存策略**
   ```
   缓存层级：
   ├── L1: 章节原文缓存（热数据，最近访问）
   ├── L2: 知识单元缓存（温数据，常用）
   └── L3: 摘要缓存（冷数据，低成本检索）
   ```

4. **批量处理优化**
   - 合并相似的AI调用
   - 使用一次调用处理多个相关任务
   - 复用上下文窗口

```python
class LearningStyle:
```

#### 3.2.3 学习风格分析算法

**数据收集来源**：
1. 用户回答问题时的反应时间
2. 用户提问的类型和频率
3. 用户对不同讲解方式的反馈
4. 用户完成练习的正确率和速度
5. 用户主动选择的学习路径

**分析算法**：

```python
def analyze_learning_style(user_history: List[LearningSession]) -> LearningStyle:
    """
    基于用户历史行为分析学习风格
    """
    style = LearningStyle()

    # 维度1：信息接收偏好分析
    # 统计用户在不同内容类型上的停留时间和互动率
    visual_engagement = calculate_engagement(user_history, 'visual_content')
    reading_engagement = calculate_engagement(user_history, 'text_content')
    # ... 其他维度

    # 使用加权平均计算各维度得分
    style.visual_score = weighted_average(visual_engagement, recency_weight=0.7)
    # ... 其他分数

    return style

def calculate_engagement(history, content_type):
    """
    计算用户对特定内容类型的参与度
    考虑因素：停留时间、互动次数、完成率、反馈评分
    """
    sessions = [s for s in history if s.content_type == content_type]
    if not sessions:
        return 0.5  # 默认中性

    engagement_scores = []
    for session in sessions:
        score = (
            session.time_spent_normalized * 0.3 +
            session.interaction_count_normalized * 0.3 +
            session.completion_rate * 0.2 +
            session.feedback_score_normalized * 0.2
        )
        engagement_scores.append(score)

    return exponential_moving_average(engagement_scores, alpha=0.3)
```

### 3.3 模块三：AI老师教导模块

#### 3.3.1 功能概述

将AI学习到的知识，以适合用户的方式进行讲解，实现真正的"教会"用户。

#### 3.3.2 教学策略体系

```
教学策略库
├── 讲解策略
│   ├── 由小到大（知识点→大知识点→知识体系）
│   ├── 由具体到抽象（例子→规律→理论）
│   ├── 由已知到未知（已有知识→新知识）
│   └── 类比教学（用熟悉的事物解释新概念）
├── 互动策略
│   ├── 苏格拉底式提问（引导思考）
│   ├── 即时反馈（答对鼓励，答错引导）
```

**间隔重复算法（简化版SM-2）**：

```python
class SpacedRepetition:
    def calculate_next_review(
        self,
        quality: int,        # 回忆质量 (0-5)
        repetitions: int,    # 已重复次数
        ease_factor: float,  # 难度因子
        interval: int        # 当前间隔（天）
    ) -> Tuple[int, float]:
        """
        计算下次复习时间
        """
        if quality >= 3:  # 回忆成功
            if repetitions == 0:
                new_interval = 1
            elif repetitions == 1:
                new_interval = 6
            else:
                new_interval = round(interval * ease_factor)

            new_ease = ease_factor + (0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02))
            new_ease = max(1.3, new_ease)
        else:  # 回忆失败
            new_interval = 1
            new_ease = ease_factor
            repetitions = 0

        return new_interval, new_ease
```

```python
class KnowledgeGraph:
    def __init__(self):
        self.nodes = {}  # node_id -> KnowledgeNode
        self.edges = []  # List of Edge

    def build_from_book(self, book: Book):
        """
        从书籍构建知识图谱
        """
        # 1. 为每个知识单元创建节点
        for chapter in book.chapters:
            for unit in chapter.knowledge_units:
                node = KnowledgeNode(
                    id=unit.id,
                    type=self.classify_node_type(unit),
                    content=unit.summary,
                    metadata={
                        'chapter': chapter.title,
                        'difficulty': unit.difficulty_level,
                        'importance': self.calculate_importance(unit)
                    }
                )
                self.nodes[node.id] = node

        # 2. 建立节点间的关系
        self.build_relationships()

    def build_relationships(self):
        """
        建立知识节点间的关系
        """
        for node_a in self.nodes.values():
            for node_b in self.nodes.values():
                if node_a.id == node_b.id:
                    continue

                # 计算语义相似度
                similarity = self.calculate_similarity(node_a, node_b)

                # 识别依赖关系
                dependency = self.detect_dependency(node_a, node_b)

                # 识别对比关系
                contrast = self.detect_contrast(node_a, node_b)

                if similarity > 0.7:
                    self.add_edge(node_a.id, node_b.id, 'similar', similarity)
                if dependency:
                    self.add_edge(node_a.id, node_b.id, 'depends_on', dependency)
                if contrast:
                    self.add_edge(node_a.id, node_b.id, 'contrasts_with', contrast)
```

### 4.2 学习风格分析算法

```python
class LearningStyleAnalyzer:
    def __init__(self):
        self.style_model = LearningStyle()
        self.confidence = 0.0

    def update_from_session(self, session: LearningSession):
        """
        从学习session中更新学习风格模型
        """
        # 提取行为特征
        features = self.extract_behavioral_features(session)

        # 使用贝叶斯更新风格模型
        self.bayesian_update(features)

        # 更新置信度
        self.update_confidence(session)

    def extract_behavioral_features(self, session: LearningSession) -> Dict:
        """
        提取行为特征
        """
        return {
            # 对不同内容类型的反应
            'visual_engagement': self.measure_engagement(session, 'visual'),
            'text_engagement': self.measure_engagement(session, 'text'),
            'interactive_engagement': self.measure_engagement(session, 'interactive'),

            # 学习节奏
            'pace_preference': self.infer_pace(session),

            # 理解模式
            'prefers_examples': self.detect_example_preference(session),
            'prefers_theory': self.detect_theory_preference(session),

            # 互动模式
            'question_frequency': session.question_count / session.duration,
            'question_depth': self.analyze_question_depth(session.questions),
        }

    def bayesian_update(self, features: Dict):
        """
        使用贝叶斯更新学习风格概率分布
        """
        for dimension, value in features.items():
            # P(style|features) ∝ P(features|style) * P(style)
            prior = self.get_prior(dimension)
            likelihood = self.calculate_likelihood(dimension, value)
            posterior = prior * likelihood
            posterior /= posterior.sum()  # 归一化

            self.update_dimension(dimension, posterior)
```

```python
        # 2. 批量合并相似任务
        batches = self.batch_similar_units(uncached_units)

        # 3. 为每个批次优化prompt
        for batch in batches:
            # 使用摘要而非原文
            compressed_content = self.compress_content(batch)

            # 复用上下文
            shared_context = self.get_shared_context(batch)

            # 构建优化后的调用
            call = APICall(
                prompt=self.build_efficient_prompt(compressed_content, shared_context),
                expected_tokens=self.estimate_tokens(compressed_content)
            )
            calls.append(call)

        return calls

    def compress_content(self, units: List[KnowledgeUnit]) -> str:
        """
        压缩内容，只保留关键信息
        """
        compressed = []
        for unit in units:
            # 使用已有摘要而非原文
            if unit.summary:
                compressed.append(unit.summary)
            else:
                # 生成压缩版本
                compressed.append(self.extract_key_points(unit.content))
        return '\n---\n'.join(compressed)
```

### 7.2 核心挑战与应对策略

**挑战1：书籍解析质量不一**
- 问题：不同PDF格式差异大，扫描版难以解析
- 应对：
  - 支持多种解析器，自动选择最佳
  - 提供手动校正功能
  - 对扫描版集成OCR（可选）

**挑战2：AI理解深度不稳定**
- 问题：AI对复杂概念的理解可能不准确
- 应对：
  - 多轮自评机制，不达标则重新学习
  - 保留原始内容，便于用户验证
  - 提供用户反馈通道，持续改进

**挑战3：学习风格分析准确性**
- 问题：初期数据不足，分析可能不准
- 应对：
  - 初始问卷作为冷启动
  - 明确告知用户分析结果，允许手动调整
  - 随数据积累逐步提高准确性

**挑战4：Token成本控制**
- 问题：完整学习一本书可能产生高额API费用
- 应对：
  - 分层摘要策略，减少重复处理
  - 智能缓存，避免重复调用
  - 提供成本估算，让用户有预期
  - 支持本地模型作为备选

**挑战5：知识图谱构建复杂度**
- 问题：自动构建高质量知识图谱难度大
- 应对：
  - 初期简化为章节层级关系
  - 使用向量相似度作为关系基础
  - 逐步迭代，人工辅助优化
