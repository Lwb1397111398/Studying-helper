# Android UI 设计规范 - 笔记本风格

## 设计理念

**核心风格：** 自然温暖 + 纸质笔记质感 + 点缀式手写体

**设计目标：**
- 营造"在温暖笔记本上学习"的氛围
- 让学习过程有温度感、仪式感
- 保持清晰易读的同时增加视觉趣味

## 颜色系统

### 主色调

| 用途 | 颜色名称 | 色值 | 意象 | 使用场景 |
|------|----------|------|------|----------|
| 背景 | 米白 | `#FDF8F3` | 泛黄纸张 | 页面背景 |
| 主色 | 深棕 | `#5D4037` | 墨水 | 标题、重要文字 |
| 强调色 | 橄榄绿 | `#6B7B3A` | 书签丝带 | 进度、成功、按钮 |
| 辅助色 | 暖橙 | `#D4915E` | 咖啡渍 | 高亮、待办、警告 |
| 卡片背景 | 浅棕白 | `#FAF6F1` | 纸张叠加 | 卡片、区块背景 |

### 语义颜色

| 语义 | 颜色 | 色值 |
|------|------|------|
| 成功/掌握 | 橄榄绿 | `#6B7B3A` |
| 进行中 | 暖橙 | `#D4915E` |
| 待办/提醒 | 琥珀色 | `#FF8F00` |
| 错误 | 暖红 | `#C62828` |
| 文字主色 | 深棕 | `#5D4037` |
| 文字次级 | 中棕 | `#8D6E63` |
| 文字占位 | 浅棕 | `#BCAAA4` |

## 字体系统

### 字体层级

| 层级 | 样式 | 使用场景 |
|------|------|----------|
| H1 标题 | 圆润手写体，24sp | 页面主标题 |
| H2 副标题 | 圆润手写体，20sp | 区块标题 |
| H3 小标题 | 无衬线粗体，16sp | 卡片标题 |
| Body 正文 | 无衬线常规，14sp | 正文内容 |
| Caption 说明 | 无衬线常规，12sp | 辅助说明 |
| 点缀手写 | 圆润手写体，14sp | 欢迎语、进度数字、提示 |

### 手写体使用原则

- **只用标题和关键提示**，正文保持清晰无衬线
- 欢迎语、进度数字、鼓励语用手写体
- 按钮文字不用手写体（保证可读性）

## 质感设计

### 背景

- 米白 `#FDF8F3` 作为页面背景
- 可选：添加轻微噪点纹理（CSS: `background-image: url("data:image/svg+xml,...")`）
- 可选：添加横线暗示（像笔记本横线）

### 卡片

- 圆角：12dp
- 背景：`#FAF6F1`（浅棕白）
- 阴影：柔和投影 `elevation: 2dp`
- 边框：可选 1dp 深棕边框 `#D7CCC8`

### 按钮

**主要按钮（纸片按钮）：**
- 背景：暖橙 `#D4915E` 或 橄榄绿 `#6B7B3A`
- 文字：白色
- 圆角：20dp（全圆角）
- 阴影：轻微投影

**次要按钮（幽灵按钮）：**
- 背景：透明
- 边框：1dp 深棕 `#5D4037`
- 文字：深棕 `#5D4037`
- 圆角：20dp

**文字按钮：**
- 背景：透明
- 文字：深棕或橄榄绿
- 无边框

### 进度条

- 轨道：浅棕 `#D7CCC8`
- 填充：深棕渐变 `#8D6E63` → `#5D4037`
- 圆角：4dp
- 高度：8dp

### 书签丝带装饰

- 位置：顶部或区块标题旁
- 颜色：橄榄绿 `#6B7B3A`
- 形状：矩形条带，可带斜切角
- 使用场景：首页标题栏、区块标题

## 组件设计

### BookCard（书籍卡片）

```
┌─────────────────────────────────────┐
│ █ 📕 高数上册                       │  ← 左侧深棕色书脊
│ █ 章节 12 · 知识单元 45 · 已学 30   │
│ █ ████████████░░░░░ 67%            │  ← 墨水渐变进度条
└─────────────────────────────────────┘
```

- 左侧 6dp 深棕色竖条（书脊效果）
- 圆角卡片，柔和阴影
- 进度条：深棕渐变

### UnitCard（知识单元卡片）

```
┌─────────────────────────────────────┐
│ 📖 导数的定义与应用                  │
│ 函数在某点的瞬时变化率...            │  ← 最多 2 行
└─────────────────────────────────────┘
```

- 圆角卡片
- 标题加粗
- 内容预览 2 行

### KeyPointCard（要点卡片）

```
┌─────────────────────────────────────┐
│ 🔵 ① 导数的定义                     │  ← 编号圆圈（橄榄绿）
│    函数在某点的瞬时变化率...         │
│    示例：                           │
│    • f(x) = x² 在 x=1 处的导数为 2  │
└─────────────────────────────────────┘
```

- 编号圆圈：24dp，橄榄绿背景，白色数字
- 标题：无衬线粗体
- 说明：常规文字
- 示例：列表样式，圆点前缀

### ConceptCard（概念卡片）

```
┌─────────────────────────────────────┐
│ 📌 极限                             │  ← 概念名（深棕/主色）
│    趋近于某值的概念...              │
│    示例：                           │
│    • lim(x→0) sin(x)/x = 1         │
└─────────────────────────────────────┘
```

- 概念名：深棕主色，粗体
- 定义：常规文字
- 示例：列表样式

## 页面设计

### 首页（BooksScreen）

- 顶部：书签丝带装饰条（橄榄绿）
- 欢迎区：手写体欢迎语 + 学习统计
- 操作区：2x2 网格纸片按钮
- 书籍列表：带书脊效果的卡片

### 书籍详情页（BookDetailScreen）

- 书籍信息卡片：标题、作者、统计
- 操作按钮：流式布局，纸片按钮
- 单元列表：简洁卡片

### 知识单元页（UnitDetailScreen）

- 标题：手写体
- 内容区：圆角卡片
- 要点/概念：结构化卡片
- 操作区：纸片按钮

### 教学页（TeachingScreen）

- 进度指示：阶段列表 + 当前高亮
- 消息卡片：圆角 + 柔和阴影
- 操作按钮：底部固定

### 考试页（ExamScreen）

- 题目卡片：圆角 + 柔和阴影
- 选项：纸片按钮样式
- 进度：顶部线性进度条

## 技术实现

### Compose 主题配置

```kotlin
// Color.kt
val PaperWhite = Color(0xFFFDF8F3)
val InkBrown = Color(0xFF5D4037)
val BookmarkGreen = Color(0xFF6B7B3A)
val CoffeeOrange = Color(0xFFD4915E)
val CardBackground = Color(0xFFFAF6F1)
val LightBrown = Color(0xFFD7CCC8)
val MediumBrown = Color(0xFF8D6E63)

// Theme.kt
private val WarmColorScheme = lightColorScheme(
    primary = BookmarkGreen,
    onPrimary = Color.White,
    secondary = CoffeeOrange,
    onSecondary = Color.White,
    background = PaperWhite,
    surface = CardBackground,
    onBackground = InkBrown,
    onSurface = InkBrown,
)
```

### 自定义组件

- `BookCardWithSpine`: 带书脊效果的书籍卡片
- `BookmarkRibbon`: 书签丝带装饰
- `PaperButton`: 纸片按钮
- `InkProgressBar`: 墨水进度条
- `KeyPointCard`: 要点卡片
- `ConceptCard`: 概念卡片
