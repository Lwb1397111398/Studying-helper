Studying-helper 学习辅助（Windows 单文件版）
============================================

1) 双击 StudyingHelper.exe 即可使用（会自动打开浏览器）。
2) 想用真 AI：安装 LM Studio 并加载模型（默认连 http://127.0.0.1:1234），
   或在网页「设置」里填写云端 API Key。不配也能用，系统会自动降级。
3) 全部数据在 exe 同级的 data\ 目录（数据库、上传的书、配置）。
   备份/搬家：拷走 exe + data\ 即可。

高级：
- 环境变量 APP_DATA_DIR=路径  → 自定义数据目录
- 环境变量 APP_LAN=1         → 监听 0.0.0.0，方便手机连同一台电脑同步
- 环境变量 APP_PORT=8765     → 固定端口
- 环境变量 APP_NO_BROWSER=1  → 不自动开浏览器
