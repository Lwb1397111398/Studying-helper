## 1. 总体架构

### 1.1 架构原则

- **后端即契约**：所有业务逻辑封装在后端API中，桌面端和移动端调用同一套API
- **模块独立**：每个模块有独立的数据模型、服务层、API端点，可单独部署和测试
- **依赖注入**：模块间通过接口交互，不直接引用具体实现
- **离线优先**：移动端考虑离线场景，关键数据支持本地缓存

## 2. 模块一：文档解析引擎

### 2.1 模块职责

将用户上传的书籍文件（PDF/TXT/EPUB）解析为结构化的纯文本，提取目录层级和书籍元数据。

### 2.2 模块边界

```
输入：书籍文件（二进制）
输出：ParsedDocument（纯文本 + 目录结构 + 元数据）

依赖：无（纯独立模块）
被依赖：知识拆分引擎
```

### 2.3 数据模型

```python
class BookMetadata(BaseModel):
    title: str
    author: Optional[str] = None
    publisher: Optional[str] = None
    publish_date: Optional[str] = None
    language: str = "zh"
    total_pages: Optional[int] = None
    file_type: str  # "pdf" | "txt" | "epub"
    file_size_bytes: int

    """目录项"""

    """PDF页码与文本位置的映射"""

```

## 3. 模块二：知识拆分引擎

### 3.1 模块职责

将解析后的文档按照章节结构和语义边界，拆分为最小可学习单元（知识单元），并提取每个单元的核心信息。

### 3.2 模块边界

```
输入：ParsedDocument（来自模块一）
输出：List[KnowledgeUnit]（知识单元列表）

依赖：模块一（文档解析引擎）
被依赖：模块三（AI学习引擎）、模块七（知识图谱管理）
```

### 3.3 数据模型

### 3.5 拆分算法

#### 3.5.1 规则拆分（默认）

```python
def split_by_rules(self, text: str) -> List[str]:
    """
    基于规则的文本拆分。

    算法：
    1. 按双换行符（\n\n）分割为段落
    2. 合并连续的短段落（< unit_min_length）
    3. 拆分超长段落（> unit_max_length）：
       a. 优先按句号/问号/感叹号拆分
       b. 如果单句仍超长，按逗号拆分
       c. 最后按固定长度截断
    """
    paragraphs = re.split(r'\n\s*\n', text)
    units = []
    buffer = ""

    for para in paragraphs:
        para = para.strip()
        if not para:
            continue

        if len(buffer) + len(para) < self.unit_min_length:
            buffer += "\n\n" + para if buffer else para
        elif len(para) > self.unit_max_length:
            if buffer:
                units.append(buffer)
                buffer = ""
            units.extend(self._split_long_paragraph(para))
        else:
            if buffer:
                units.append(buffer)
            buffer = para

    if buffer:
        units.append(buffer)

    return units
```

### 7.5 SM-2间隔重复算法

```python
class SpacedRepetitionAlgorithm:
    """SM-2间隔重复算法"""

    def calculate_next_review(
        self,
        quality: int,           # 回忆质量 0-5（0=完全忘记，5=完美回忆）
        repetitions: int,       # 已成功重复次数
        ease_factor: float,     # 当前难度因子
        interval: int           # 当前间隔天数
    ) -> Tuple[int, float]:
        """
        计算下次复习间隔和新的难度因子。

        返回：(新间隔天数, 新难度因子)

        算法：
        - quality >= 3（回忆成功）：
          - repetitions == 0 → 间隔1天
          - repetitions == 1 → 间隔6天
          - repetitions >= 2 → 间隔 = 上次间隔 * 难度因子
        - quality < 3（回忆失败）：
          - 重置为1天间隔，重复次数归零
        - 难度因子更新：
          - EF' = EF + (0.1 - (5-q) * (0.08 + (5-q) * 0.02))
          - 最小值 1.3
        """
        if quality >= 3:
            if repetitions == 0:
                new_interval = 1
            elif repetitions == 1:
                new_interval = 6
            else:
                new_interval = round(interval * ease_factor)
            new_ease = ease_factor + (0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02))
            new_ease = max(1.3, new_ease)
        else:
            new_interval = 1
            new_ease = ease_factor

        return new_interval, new_ease

    def quality_from_correctness(self, is_correct: bool,
                                  response_time: float,
                                  avg_time: float) -> int:
        """
        从正确性和响应时间推算质量分数。

        - 正确 + 快速（<平均时间） → 5
        - 正确 + 正常速度 → 4
        - 正确 + 慢速 → 3
        - 错误 + 有部分正确 → 2
        - 错误 + 完全错误 → 1
        - 未回答 → 0
        """
```

### 7.6 掌握度评估算法

```python
class MasteryEvaluator:
    """掌握度评估器"""

    def evaluate(self, history: List[TestHistory],
                 annotations: List[Annotation]) -> MasteryAssessment:
        """
        综合评估掌握度。

        维度及权重：
        - recall_accuracy: 0.3（回忆准确率）
        - response_speed: 0.15（回答速度，越快越熟练）
        - consistency: 0.2（多次测试表现稳定性）
        - explanation: 0.2（解释能力）
        - application: 0.15（应用能力）

        等级划分：
        - score >= 0.9 → 'mastered'
        - score >= 0.7 → 'proficient'
        - score >= 0.4 → 'familiar'
        - score < 0.4 → 'beginner'
        """
        recall = self._calc_recall_accuracy(history)
        speed = self._calc_response_speed(history)
        consistency = self._calc_consistency(history)
        explanation = self._calc_explanation_ability(history)
        application = self._calc_application_ability(history)

        score = (recall * 0.3 + speed * 0.15 + consistency * 0.2 +
                 explanation * 0.2 + application * 0.15)

        # 有"不懂"标记的扣分
        confusing_count = sum(1 for a in annotations if a.annotation_type == 'confusing')
        score -= confusing_count * 0.05
        score = max(0, score)

        level = self._score_to_level(score)

        return MasteryAssessment(
            unit_id=history[0].unit_id if history else "",
            score=score,
            level=level,
            dimensions={
                'recall_accuracy': recall,
                'response_speed': speed,
                'consistency': consistency,
                'explanation': explanation,
                'application': application
            },
            weak_points=self._identify_weak_points(history),
            recommended_review_at=self._calc_next_review(score, history)
        )
```

## 11. 全局约定

### 11.1 命名规范

- 文件名：`snake_case.py`
- 类名：`PascalCase`
- 函数/方法名：`snake_case`
- 常量：`UPPER_SNAKE_CASE`
- 数据库表名：`snake_case`（复数，如 `knowledge_units`）
- API路径：`kebab-case`（如 `/api/v1/knowledge-units`）

### 11.2 时间格式

- 数据库存储：ISO 8601字符串（`2026-05-26T10:30:00Z`）
- API传输：ISO 8601字符串
- 时区：统一使用UTC，客户端负责本地化

### 11.3 ID格式
